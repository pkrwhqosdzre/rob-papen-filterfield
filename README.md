## Overview

FilterField is a creative filter plugin with a 2D X/Y modulation field that controls three independent filter bands simultaneously, with side-chain triggering for dynamic filter effects.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Rob Papen FilterField** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **X/Y Field** | Two-dimensional field moves three filter cutoff points simultaneously |
| **Three Filter Bands** | Independent LP, BP, and HP bands with resonance and drive |
| **Side-Chain** | Side-chain audio input triggers X/Y field movement with envelope |
| **LFO Modulation** | Syncable LFO automates field position for rhythmic filter sweeps |
